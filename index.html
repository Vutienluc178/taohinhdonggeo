Kết nối Google Sheet

Dùng Google Apps Script làm cầu nối để lưu & đồng bộ thư viện code lên Google Sheet của bạn — không cần server riêng.

Chưa có Web App? Hướng dẫn tạo (5 bước, ~2 phút)
  1. Mở Google Sheets, tạo một trang tính mới (đặt tên tùy ý, VD "Thư viện GeoGebra").
  2. Vào menu Tiện ích mở rộng (Extensions) → Apps Script.
  3. Xóa hết code mặc định trong file Code.gs, dán toàn bộ đoạn mã bên dưới vào, rồi bấm biểu tượng Lưu 💾.
  4. Bấm Triển khai (Deploy) → Triển khai mới (New deployment). Chọn loại Ứng dụng web (Web app). Mục "Thực thi với quyền của" (Execute as) chọn Tôi (Me), mục "Người có quyền truy cập" (Who has access) chọn Bất kỳ ai (Anyone). Bấm Triển khai và cấp quyền khi được hỏi.
  5. Sao chép đường dẫn Web app URL vừa tạo, dán vào ô phía trên rồi bấm "Lưu URL & tải dữ liệu".
